# Market Modelling: R code

Code that accompanies the blog **Market Modelling**, where I explain how
market modelling can shape business decisions, with stories of famous decisions 
along the way.

Blog: https://market-modelling.blogspot.com

## What's inside

| Folder | Topic | Blog post |
|---|---|---|
| `01-cournot` | Cournot model: competing on quantity | [Read the post](LINK) |

## How to run the scripts

1. Install R (and optionally RStudio).
2. Download a script from this repository.
3. Open it in R and run it. No extra packages are needed.

## Please note

All models are simplified illustrations using invented numbers. They are
meant for learning, not as predictions for any real company.
